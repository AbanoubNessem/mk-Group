===========================================
إعداد قاعدة البيانات mk_group
===========================================

الطريقة الأسهل والأسرع:

1. افتح phpMyAdmin (http://localhost/phpmyadmin)

2. في تبويب SQL، قم بتشغيل هذا الأمر:
   CREATE DATABASE `mk_group` CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

3. بعد إنشاء قاعدة البيانات، قم بتشغيل ملف SQL:
   - افتح ملف: database/create_mk_group_database.sql
   - انسخ محتواه
   - الصقه في phpMyAdmin في تبويب SQL
   - تأكد من اختيار قاعدة البيانات mk_group
   - اضغط Go

4. قم بتحديث ملف .env:
   - افتح ملف .env في جذر المشروع
   - غيّر السطر:
     DB_DATABASE=ag_designss
   - إلى:
     DB_DATABASE=mk_group

5. قم بتشغيل:
   php artisan config:clear
   php artisan cache:clear

6. تحقق من أن كل شيء يعمل:
   - افتح الموقع في المتصفح
   - افتح Dashboard

===========================================
ملاحظات مهمة:
===========================================

- تأكد من أن قاعدة البيانات ag_designss موجودة وتحتوي على البيانات
- إذا كانت قاعدة البيانات ag_designss فارغة، يمكنك استخدام:
  php artisan migrate
  بدلاً من نسخ البيانات

- إذا واجهت مشاكل، تأكد من:
  * اسم المستخدم وكلمة المرور في ملف .env صحيحة
  * MySQL/MariaDB يعمل
  * قاعدة البيانات ag_designss موجودة
